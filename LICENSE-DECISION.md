# License decision required

This repository currently has **no open-source license**. That is the safest default for a private repository containing research code and possible third-party contributions.

Before making the repository public, confirm:

1. ownership and University of Houston policy for code created during sponsored research;
2. permission for code or models contributed by collaborators;
3. compatibility with MCmatlab, MCX, datasets, and any other third-party licenses;
4. whether patent or manuscript submission timing limits public disclosure.

After those checks, a permissive license such as BSD-3-Clause or MIT may be appropriate. Do not add one solely for appearance: a license grants legal reuse rights.
