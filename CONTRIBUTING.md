# Contributing

This is a curated research repository. Proposed changes should:

- preserve original numerical parameters unless a correction is explicitly documented;
- identify the source dataset and required external packages;
- avoid absolute machine-specific paths;
- place generated data and figures under ignored output directories;
- include a short MATLAB help header describing purpose, inputs, outputs, and lineage;
- pass `tools/check_repository.sh` before commit.

Do not commit credentials, protected health information, unpublished participant data, proprietary meshes, or third-party content without redistribution permission.
